# 📊 Superstore Sales Analysis using SQL

## 📌 Project Overview

This project analyzes the Superstore Sales dataset using SQL to extract meaningful business insights. The analysis focuses on sales performance, customer behavior, product trends, regional performance, and profitability using real-world business questions.

## 🎯 Key Insights

- Technology generated the highest sales.
- The West region recorded the highest sales.
- A small group of customers contributed a significant share of total revenue.
- Some products generated high sales but low profit margins.
- Sales showed seasonal variations across different months.
