# 🏥 Hospital Management System Analysis using SQL

## 📌 Project Overview

This project analyzes hospital management data using SQL to generate operational, financial, and patient-care insights. The analysis answers real-world business questions that help monitor hospital performance, patient admissions, billing, and departmental efficiency.
