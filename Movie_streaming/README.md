# 🎬 Movie Streaming Platform Analysis using SQL

## 📌 Project Overview

This project analyzes a **movie streaming platform** dataset using SQL to discover viewing patterns, user engagement, content popularity, and subscription insights. The queries answer real business questions that a streaming company might use for decision-making.

---

## 📂 Dataset Information

| Attribute | Details |
|-----------|---------|
| Dataset | Movie Streaming Watch History |
| Format | CSV |
| Database | MySQL |
| Table | watch_history |

## 📈 Business Problems Solved

- Top 10 Most Watched Movies/Shows
- Most Watched Genres
- Average Watch Time per User
- Average Completion Rate per Title
- Trending Shows by Region
- Inactive Users (Last 30 Days)
- Average Rating by Genre
- Device Usage Analysis
- Subscription Type vs Average Watch Time
- Most Active Regions
- Top Users by Total Watch Time
- Daily Watch Trends
- Lowest Completion Rate Titles
- Average Rating by Subscription Type
- Genre Popularity by Region
